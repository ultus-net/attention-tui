# attention-tui

A terminal pane that answers one question: does anything need me right now?

Teams chats and Outlook mail, filtered by rules you write, in a pane that stays
signed in. Status: in development. The design lives at
`docs/superpowers/specs/2026-11-12-attention-tui-design.md` and the
implementation plan at `docs/superpowers/plans/2026-11-12-attention-tui.md`.
